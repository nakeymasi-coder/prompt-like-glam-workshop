What is HTML?

HTML creates the structure of your webpage.

What is CSS?

CSS controls how your webpage looks.

What is JavaScript?

JavaScript makes buttons, generators and interactive features work.

What's the difference?

HTML builds it. CSS styles it. JavaScript makes it work.

Paste this directly under your main generator title.

<div class="generator-header-image">
  <img src="images/header-image.png" alt="Generator header image" />
</div>
HTML

Add a Marquee

Paste this under the header image.

<div class="generator-marquee">
  <div class="marquee-track">
    <span>Customize your generator ✦ Make it your own ✦ Add your brand style ✦</span>

  </div>
</div>
CSS

Style Your Customizations

Footer

Use a simple copyright footer only. No extra footer clutter.

Help Center

Fast fixes for common workshop problems.

Keep students moving without stopping the whole class.

CSS is not showing

Make sure the file path is exactly css/style.css.

JavaScript is not working

Make sure the file path is exactly js/script.js.

Buttons do nothing

Check that the ID in HTML matches the ID used in JavaScript.

Netlify page is blank

Make sure the homepage file is named index.html.

GitHub is not updating

Save, commit, and push. Netlify updates after GitHub updates.

Copy button fails

Use a local server or published site. Some browsers block clipboard on file URLs.
