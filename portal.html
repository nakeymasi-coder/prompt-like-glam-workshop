Act as a patient business coach and beginner-friendly e-commerce website planner. Help me complete my “My Store in One Page” worksheet for the Build Your Brand World workshop.

Quick Help

Simple answers you can use in any workshop.

HELP

Quick Help

What is HTML?

HTML creates the structure of your prompt generator. It builds the headings, buttons, text boxes, cards, and everything users can see.

What is CSS?

CSS controls the appearance of your generator, including colors, fonts, spacing, layouts, borders, and animations.

What is JavaScript?

JavaScript powers the interactive features like Generate Prompt, Randomize, Copy, Presets, and other buttons.

What's the difference between HTML, CSS, and JavaScript?

Think of it like a house: HTML builds it, CSS decorates it, and JavaScript makes everything work.

Where do I paste the ChatGPT prompts?

Copy the lesson prompt from this companion and paste it into a new ChatGPT conversation. Then copy the generated code into the correct file.

How do I know which file to edit?

Each lesson tells you whether you're working in index.html, style.css, or script.js. Always paste the code into the matching file.

How do I change my generator's colors?

Open style.css, find the color variables near the top, and replace them with your own brand colors.

How do I add my own header image?

Add your image to the project folder, then update the image path in index.html to point to your file.

How do I publish my generator?

Save your project, commit and push it to GitHub, then deploy it with Netlify to create your live website.

My generator isn't working. What should I do?

Make sure your files are saved, the code was pasted into the correct file, and check your browser's Console for any errors.

Common Mistakes

Keep these reminders handy while you build.

REMEMBER

Common Mistakes

  • Always save your file before refreshing your browser.
  • Paste the generated code into the correct file (index.html, style.css, or script.js).
  • Never overwrite your entire file unless the lesson tells you to.
  • Copy the entire response—don't stop halfway through the code.
  • Only ask ChatGPT to generate one file at a time.
  • Read the lesson instructions before pasting any code.
  • If something breaks, undo your last change before trying something else.
  • One missing quotation mark, bracket, or semicolon can break your generator.
  • Check the browser Console for errors before asking for help.
  • Test your generator after every major change instead of waiting until the end.

Day 2

Improve, Customize & Finish Your Project

Start with the working project you completed on Day 1. Improve what matters, add your finishing touches, test it, and get it ready to publish.

Step 1

Review & Choose What to Improve

Take a quick look at your working Day 1 project and decide what you actually want to improve today.

  • Keep everything that is already working.
  • Notice anything that feels limited, unfinished, or unclear.
  • Choose only the improvements that matter to your project.
Step 2

Expand or Improve Your Project

Strengthen the content, choices, sections, tabs, or features that apply to the type of project you built.

  • Prompt generator: improve categories and option choices.
  • App or tool: improve screens, tabs, content, or interactions.
  • Website: improve sections, content, links, or features.
  • Change only what you approve.
Step 3

Finalize Project-Specific Features

Finish the special features your project actually needs. This step adapts to the project instead of forcing the same features on everyone.

  • Prompt generator: finalize presets and generator-specific behavior.
  • App or tool: finalize tabs, actions, saved information, or outputs.
  • Website: finalize forms, buttons, navigation, downloads, or links.
  • Skip features that do not belong to your project.
Step 4

Add Your Finishing Touches

Add only the visual finishing touches you want. These are optional customizations, not requirements.

Header Image

Add or update a branded image near the top of your project.

Scrolling Marquee

Add a clean scrolling message when it fits your design.

Footer & Copyright

Finish the bottom of the project with your correct name or brand.

Step 5 · Optional

Add Premium Features

Add extra outputs or advanced features only when they make the project more useful. Skip this step when you do not need it.

  • Keep the working Day 1 structure intact.
  • Add only features that fit this specific project.
  • Test every added feature before moving on.
Step 6

Final Test & Fix

Test the finished project one section at a time and fix only problems that are actually found.

  • Test the main action and all approved interactive features.
  • Check links, forms, buttons, tabs, or outputs that exist.
  • Check desktop and mobile layouts.
  • Fix errors without redesigning working sections.
Step 7

Ready to Publish

Your build is finished. Make sure you saved the final files, then continue to publishing and selling.

  • Save index.html, style.css, and script.js.
  • Open the project one final time.
  • Make sure the version you tested is the version you publish.

Download your files and follow these simple steps to open and customize your Workshop Companion.

1
First Step

Download the Workshop Companion ZIP

Start by downloading the Workshop Companion ZIP file to your computer. A ZIP file is a folder that has been compressed so it is easier to download and share.

Follow Along with the Screenshot

  1. Click the download button provided with your Workshop Companion.
  2. Wait for the ZIP file to finish downloading.
  3. Open your computer’s Downloads folder.
  4. Look for the Workshop Companion ZIP file.
Beginner Tip: Do not try to open or edit the project while it is still inside the ZIP file. You must extract it first.
2
Second Step

Extract the ZIP File

Extracting the ZIP turns it back into a normal folder that you can open and edit.

Follow Along with the Screenshots

  1. Right-click the Workshop Companion ZIP file.
  2. Click Extract All.
  3. Choose where you want the new folder to be saved.
  4. Click Extract.
  5. Wait for the new folder to open.
Beginner Tip: Use the new extracted folder from now on. Do not keep working inside the original ZIP file.
3
Third Step

Open the Project in Visual Studio Code

Now you'll open the Workshop Companion in Visual Studio Code so you can begin customizing it.

  1. Open Visual Studio Code.
  2. Click File, then click New Window.
  3. In the new window, click File again, then click Open Folder....
  4. Find the Workshop Companion folder you extracted in Step 2.
  5. Select the Workshop Companion folder.
  6. Click Select Folder, or Open if that is what your computer shows.
  7. Wait for the project files to appear in the Explorer panel on the left side of VS Code.
Beginner Tip: Open the main Workshop Companion folder, not one of the folders inside it. You should see files like index.html, style.css, and script.js.

Follow Along with the Screenshots

4
Fourth Step

Understand the Project Structure

Before you start editing, it's helpful to know what each file does. You do not need to memorize this. Just use it as a quick reference.

index.html

This file contains the content and structure of your Workshop Companion. Most text, buttons, and sections are found here.

style.css

This file controls how your Workshop Companion looks, including colors, fonts, spacing, borders, and layouts.

script.js

This file controls how the Workshop Companion works. It handles buttons, menus, pop-ups, copying text, and other interactive features.

Assets & Downloads

These folders hold images, icons, downloadable files, and other resources used by the Workshop Companion.

Beginner Tip: If you're only changing wording, you'll usually work in index.html. If you're changing colors or fonts, you'll usually work in style.css.
5
Fifth Step

Use ChatGPT to Customize Your Workshop Companion

You can use ChatGPT to help you change the wording, colors, images, buttons, downloads, and branding without trying to figure everything out by yourself.

Workshop Prompt

Workshop Companion Master Customization Prompt

Click Copy Prompt, then paste it into a new ChatGPT conversation to begin customizing your Workshop Companion.

Beginner Tip: Keep Visual Studio Code and ChatGPT open at the same time. This makes it easier to copy code, paste changes, save your work, and test each step.
Important: Never replace an entire file unless ChatGPT clearly tells you to. Small, careful changes are safer and easier to fix.

Quick Reference

Common VS Code Keyboard Shortcuts

Keep this list handy while you work in any workshop.

Shortcut What It Does
Ctrl + A Select everything in the current file.
Ctrl + C Copy the selected text.
Ctrl + V Paste copied text.
Ctrl + X Cut the selected text.
Ctrl + F Find text inside the current file.
Ctrl + H Find and replace text inside the current file.
Ctrl + Shift + F Search across every file in the project.
Ctrl + G Jump directly to a specific line number.
Ctrl + S Save your changes.
Ctrl + Z Undo your last change.
Ctrl + Y Redo a change you undid.
Ctrl + Shift + P Open the Command Palette.
F12 Go to the code connected to the selected item.
